# Drive lessons

Append one line after a failed or surprising stroll. Write the **method**, not a waypoint list for one map.

- Traces that start in a wall report max range. If sprint cruise collapses and `fwdDist` still says open, you are kissing cover — peek anyway. Origin the probe slightly *behind* the capsule, at capsule *center*. Hunt along the walk for a *disconnected* platform (air gap or height break). Lower and close enough to fall onto = `drop` (walk off). Lower across too much air = `jumpDown`. Higher within jump apex = `jumpUp`. Same level after a gap = `cover`. Do not treat a walk-off lip as blocked.
- Recast `/goto` needs `navTiles > 0`. Empty mesh if cubes are pushed to the octree *before* Recast exists, generation is Static, or a runtime bounds volume has no brush. Create Recast, then UpdateComponentData, then Build. **TileSizeUU is a dirty zone, not link search.** Jump-gen uses JumpLength inside the NavMeshBoundsVolume (platforms + hop corridor). Never grow tiles to make a hop fit. Read Epic’s nav hub before changing bake. [RecastLinks.md](../../../Docs/RecastLinks.md).
- Recast drop links: if the fall will not kill, it is a drop link. Jump-up: full RocketPulse triple apex (~15.8 m) sets `JumpHeight` / JumpUp budget — do not use a fake 4 m. `/goto` keeps steering at the goal when Recast ends at a lip; chain air jumps while `fwdKind` is `jumpUp`.
- Do not memorize gap sides or wall X for a layout. Stop when `fwdDist` < 400 (or cruise speed collapses on two samples), peek the side that still has **floor**, resume.
- `leftDist`/`rightDist` at max range is “no wall,” which is how void looks. Peeking toward the larger wall-clearance walked off the strip. Confirm ground in the strafe direction; an 8 m cover can occupy the whole remaining width so one “open” side is air.
- If `|Y|` is already off the strip, **zero forward** until you are back. A short rail nudge then sprint is a void. Stalled at the edge is cover — peek across the lane without leaving the floor.
- `RescueFallenPawns` ticks; `/respawn` restarts a destroyed pawn. Still prefer not to walk off.
- Agent `"slide": true` pulses `RequestSlide()`. Crouch-hold C still needs a rising edge if you are not using the slide pulse. Hold the plan until `/state.sliding` is false; commit from `slideDistanceCm` instead of truncating or `goto`-rewriting mid-slide.
- A look-only sequence step replaced by the next POST before a 30 Hz tick never applies. Put `yawAbs`/`pitchAbs` or `lookAtSeat` on the **first movement step**, then confirm heading. Spawn pitch is often −12; hold **0** for same-height headshots and yaw at the objective. `yawAbs` is a rate-limited goal (420/280 deg/s), not a snap.
- `look.yaw` is a delta, also clamped to the agent turn cap. A 180° turn as a delta takes multiple ticks; `yawAbs` sets the goal. Use `lookAtSeat` to track a pawn (sticky point, 100 ms react if they move).
- `while: trackFocus, fire` must aim at the **other combat pawn**, not the cursor seat’s own body. Hip recoil still kicks control pitch; LookController must keep slewing pitch at `RecoilCorrectPitchRate` while spraying (do not freeze pitch for `RecoilCorrectDelay` on every shot).
- Never leave a strafe hold waiting for the next tool call (new shells are ~8 s). `/sequence` unpresses on the sim.
- Live book is `botBook.name`. Throw on loc frozen while `goto` is live using **pawn loc vs `gotoX/Y`**, not `gotoDistXY` (that is the Recast waypoint). The 682,-120 menhir kiss had a close waypoint and a far court marker. Peek `hide_center_lee` instead of re-`goto court_center`. `/state.botBook.verb` / `whiles` / `pawnStill` / `enemyDistXY` / `followAlert` (this tick) vs `lastFollowAlert`. A `:fire;` leaf is a pulse unless Hold keeps `bFire` or `while:` names `fire` — `track_fire` with only `while: trackFocus` will show `verb=fire` `agentFire=false` after ~0.12 s.
- PowerShell `-f` eats `{` in JSON. Never format a JSON body with `-f`. Prefer integer look values if you must concatenate.
- Half-cover vs full wall: `fwdDist` short and `headDist` open is **not** enough. That is also a walkable ledge and a downhill wall whose top is below eye height. Jump only at the face when floor 1 m ahead is not a step. Sequence `"jump": true` on the sprint step only then.
- `/goto` can freeze with traces open. Jump-sprint unsticks; do not peek. Z collapse on a lane is still a map bug — stop if Z falls out. The old west through-floor band (~x −85 to −122 m) is off the compressed 3-lane.
- Engine `WebSocketServer` does not export `FWebSocketServerModule`. HTTP `POST /hub` on 18765 and WS 18766 share `FCLHubCommandRegistry` (including `appendBotBook`).
- Through-floor (Z collapses while still on-lane) is a **map** collision bug, not a peek failure. Stop; do not keep strafing.
- `AAIController` copies pawn yaw onto control rotation every tick (`bSetControlRotationFromPawnOrientation`). A combat body possessed by that default will crawl spawn-heading instead of following hub `goto`. Seat controllers must no-op `UpdateControlRotation`.
- `goto` pair stall: count arrival when DistXY is already inside the radius even if `goto` is still true (micro-adjust in place looks like an 8s stall). Skip `StartGoto` when already inside arrive.
- Cursor is a **SeatMotor subtype** (`kind: cursor`), not a bool and not an MCP filter. Hub push is `WantsHubSnapshot`; Cursor only gets `stale`.
- Survivability: sample `health` / `shield` / `alive` per seat. Shield 0 or health below max → stop holding fire, break LOS, wait the 3 s regen delay before a full re-peek. Peek-shoot; B is not a turret. Death is expected — `WaitAlive` and resume; do not throw or mute the gunfight.
- Cover before first shot. Do not `goto` both seats through the pit at once — A shoves B off path. Seat B at the hide lee `(0,400,−600)` first, then A to a trilithon. Parallel pair to `(0,140)` sat B on A’s y=0 chord.
- Lintel stick is catalog `megalith_hop` / `jump_lintel`: **`airDive marker=menhir_N`**, not MCP `plan` and not `/goto`. The leaf jumps, faces the marker (≤18°), dives, and releases. Inner is only on-slab (~2.2 m). Envelope climb cap is triple apex. Leftover `trackFocus` sends the hop into the pit. Stick test: `z ~-1577`, DistXY < 180 — pit stand is **−1902**. Drop off the stone before `goto` home; send seats one at a time.
- `airDive marker=` is jump-then-dive (`AirDiveTo`) for lintels. `goto` Launchs **only** Recast off-mesh with `UCLNavArea_AirDive` (FindPath owned that hop). Catalog `edge_pad` is Recast `goto` only — do not JIT `airDive` the island when FindPath misses; say so and fix Recast. AirDive `DefaultCost` 50 so short terrace chords lose to walk/DropDown. Recast-owned Launch still flies (recipe or recastLaunchFallback); envelope is not a veto. Standing on the island 0.45 s recalls to the lip; void below the island uses the same lip teleport.
- `goto` path+stick with loc glued and `ctrlYaw` frozen at spawn facing is **not** Recast. `lookYaw` is the desired heading; `move=` is the computed stick, not CMC proof. If `ctrlYaw` never leaves spawn yaw (Red ~0, Blue ~180) while `lookYaw` is tens of degrees off, look/move never applied. Standalone `goto` working and two-box glued means CharacterMovement did not `ControlledCharacterMove` that body (`IsLocallyControlled` / `ServerMove`), not a missing book.
